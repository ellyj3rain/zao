## Record

ZAO now owns an exact, durable turned-source side of Afflicted return. The
death sequence authorizes one recovery event. Loaded, fake-dead, virtualized
and reanimated-registry sources are held with their current material state
before SAO can publish a living destination. Removal requires the same event,
person and source identity; acknowledgment is durable and repeated callbacks
resume the transaction without removing another body.

Native hooks preserve held sources before the Lua bridge is available.
Registry loading restores the omitted hand reference before later callbacks
can change inventory. A missing source does not authorize a clone. Ordinary and
fake-dead sources can reconstruct one unpublished checkpoint-owned source; an
offscreen return can therefore finish in durable living state without claiming
a loaded controller. Per-identity callback failure isolates the affected source
and retains its prior checkpoint while unrelated sources continue.

Returned people are critically viable and still injured. The production Java
operation clears lethal and fake Knox flags and timers, zombie fever and the
native zombie-infection flag. It restores only enough weighted health to reach
the return floor. Wounds, treatments, fractures, ordinary wound infection,
statistics and experience remain. The next native BodyDamage update remains
alive. SAO stores Knox as systemically dormant; the return does not roll a
spontaneous Crossed transition.

## Verification

The complete gate passes with all seven borders. The native source border runs
the installed population and reanimated serializers and 37 compiled defect
controls. The physiology border loads a world-version-249 death snapshot,
executes the production operation and the next native update, and rejects four
defects: surviving lethal infection, scalar-only health, erased injuries and a
full heal. The joint SAO instrument covers authorization, callback ordering,
possessions, loaded and dormant paths, retry, repeated death and diagnostics.

These checks do not establish a rendered loaded-world return, a complete
running-save reopen, or atomic recovery from interruption between the engine's
separate persistence surfaces.
